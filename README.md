# 예비군 D-day

상근예비역 훈련 준비를 날짜별로 챙기는 단일 파일 웹앱입니다.
훈련명·유형·기간·편성일만 넣으면 **편성일부터 훈련 종료 다음날까지** 할 일이 자동으로 만들어집니다.

## 쓰는 방법

1. 아래 주소를 아이폰 사파리로 엽니다.
2. 공유 버튼 → **홈 화면에 추가**를 누르면 앱처럼 전체 화면으로 열립니다.
3. `훈련 추가`에서 훈련명, 유형, 시작일(D-DAY), 종료일, 편성일을 넣고 저장합니다.

## 탭

- **오늘 할 일** — 기준 날짜의 할 일, 밀린 할 일, 7일 안에 할 일. 날짜를 넘겨 미리 볼 수 있습니다.
- **훈련 목록** — 등록한 훈련별 D-day 진행률과 단계(편성 직후 → 종료 후)별 할 일.
- **상시 업무** — 매일·매주·매월·분기 반복 업무와 회차별 체크.
- **지침 검색** — 지침서 19개 항목을 검색어로 바로 찾기.

## 자동으로 잡히는 일정

| 시점 | 할 일 |
| --- | --- |
| 편성 당일 | 전자고지·알림톡 발송, 무기수불대장 인쇄·훈련 탑재 |
| 편성 +5일 | 전자문서 발송결과 확인·홍보메일, 1·2차 우편통지, 3차 전자고지·전화 |
| D-15 ~ D-8 | 소집통지서 결산 |
| D-7 ~ D-3 | 3차 미교부 보고 |
| D-3 ~ D-2 | 참석 독려문자 |
| D-1 | 연기자·보류자 입력, 독려 재발송, 3차 고발예고 |
| D-DAY | 업무연락 대대 업로드 자료 확인 |
| 종료 +1 | 무단불참자 출귀국 확인·정정요청, 숫자 대조·교육훈련철 결재 |

- 주말·공휴일은 직전 평일로 당겨서 표시합니다(끄고 켤 수 있음).
- 훈련 유형이 **작계**면 D-1에 작계 준비 항목이,
  **전국단위 포함**을 켜면 D-1에 홍보메시지·3차 통화 항목이 자동으로 붙습니다.
- 2026~2027년 공휴일이 기본으로 들어 있고, 임시공휴일은 직접 추가할 수 있습니다.

## 데이터

- 모든 데이터는 브라우저의 localStorage(`reserveTodo.v1`)에만 저장됩니다. 서버로 전송되지 않습니다.
- 설정에서 JSON 내보내기/불러오기로 백업할 수 있습니다. 기기를 바꾸면 이 JSON으로 옮기면 됩니다.
